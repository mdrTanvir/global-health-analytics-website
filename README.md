# Global Health Analytics

An accessible portfolio website for a global health analysis of maternal mortality and life expectancy. It explains the research question, the main country-level patterns, and the analytical approach in plain language before introducing the technical details.

**Live site:** [health.tanvirrahman.dev](https://health.tanvirrahman.dev/)

## What the site covers

- The global health question behind the analysis
- Three country-level outcome patterns and what they mean
- A plain-language view of the findings for non-technical readers
- Technical notes on data preparation, clustering, validation, and limitations

## Research source

The analysis and notebooks are available in the [SDG Health Analytics repository](https://github.com/mdrTanvir/SDG-Health-Analytics).

## Run locally

The deployable Next.js application is in [`vercel-app`](./vercel-app).

```bash
cd vercel-app
npm install
npm run dev
```

## Deployment

The website is deployed on Vercel from the `vercel-app` directory. No environment variables are required.
